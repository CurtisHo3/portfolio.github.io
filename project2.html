Jazz Melody Generation with Transformers

Course: APS 360 | Date: Fall 2025

Project Overview

Developed a Transformer-based neural network to generate jazz melodies conditioned on chord progressions. The model learns from MIDI data to create musically coherent solos that respect harmonic structure.

PyTorch Transformers Music Theory MIDI Processing

Key Achievements

  • 25.77% Pitch Accuracy - Model successfully predicts melodic intervals
  • 79.68% Duration Accuracy - Strong rhythmic pattern learning
  • Chord-Conditioned Generation - Melodies respect harmonic progressions
  • 1800+ MIDI Files Processed - Curated jazz dataset from multiple sources

Problem Statement

Algorithmic music generation has traditionally relied on rule-based systems that lack the creative flexibility of human musicians. The challenge was to develop a system that could:

  • Generate jazz melodies that are harmonically appropriate
  • Maintain musical coherence over extended sequences
  • Respect both pitch and rhythmic patterns from training data
  • Allow user control through chord progression input

Technical Approach

Data Pipeline

Built a comprehensive MIDI processing pipeline that:

  • Quantization: Time-aligned notes to 16th note grid (0.125s)
  • Chord Detection: Sliding window algorithm identifies pitch class sets every 0.5s
  • Interval Encoding: Hybrid representation using absolute pitches and relative intervals
  • Rest Handling: Explicit rest tokens preserve rhythmic structure

            chord_label = "-".join(str(pc) for pc in pcs)

        chords.append((t, chord_label))

Model Architecture

Implemented a custom Transformer architecture with:

  • 6 Encoder/Decoder Layers with 8 attention heads
  • Embedding Dimensions: 64 (notes) + 32 (chords) + 32 (durations) = 128D
  • Causal Masking: Prevents the model from looking at future tokens
  • Dual Output Heads: Separate prediction for pitch and duration

Training Process

The model was trained for 15 epochs using:

  • Optimizer: AdamW with learning rate 1e-4
  • Scheduler: ReduceLROnPlateau (patience=4, factor=0.5)
  • Regularization: 40% dropout, gradient clipping (max_norm=1.0)
  • Data Split: 80% train, 10% validation, 10% test

Technical Insights

Interval vs. Absolute Pitch Encoding

The model uses a hybrid approach combining absolute pitches (after rests) and relative intervals (between consecutive notes). This reduces vocabulary size while maintaining melodic contour information.

Causal Masking Implementation

Implemented custom mask generation to ensure autoregressive properties:

def generate_square_subsequent_mask(self, sz):
    mask = (torch.triu(torch.ones(sz, sz)) == 1).transpose(0, 1)
    mask = mask.float().masked_fill(mask == 0, float('-inf'))
    return mask

Rest Penalty During Generation

To prevent excessive rests, a penalty factor (7.0) is applied to rest token logits during sampling, encouraging more continuous melodic lines.

Challenges & Solutions

Challenge: Pitch Range Explosion

Problem: Interval accumulation caused pitches to exceed MIDI range (0-127)

Solution: Implemented clamping to keep pitches between C0 (21) and C8 (108) during generation

Challenge: Sparse Chord Coverage

Problem: Only 40% of timesteps had recognizable chord labels

Solution: Filtered dataset to retain only notes with valid chord annotations, improving training signal

Challenge: Sequence Length Alignment

Problem: Generated melodies exceeded chord progression duration

Solution: Implemented time-tracking during generation with early stopping when target duration is reached
